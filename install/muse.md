# Install Pine in Muse

Connect `https://mcp.pine.im/mcp` through a Custom Connector. Request
`mcp:tools offline_access` on the first OAuth authorization so the connection can
refresh without repeated sign-in.

Import the official [Pine skill](../plugins/pine/skills/pine/SKILL.md) and
[reference files](../plugins/pine/skills/pine/references/), preferably unchanged and with their
relative paths preserved. Verify that Pine tools are available.
